# ファイルまとめツール
## CUstomTkinterを使用した複数のフォルダ、ファイルを1つにまとめるツール
自信のソースを他者に展開する時、フォルダ・ファイルをまとめるようとして作成したツールです。

## 実行イメージ
### 実行画面
![実行画面](docs/01_release_porter(初期画面).png)
![実行画面](docs/02_release_porter(フォルダ選択).png)

## できること
- 選択したフォルダ・ファイルを一つのファイルにまとめてコピーする  

## 使用技術
- Python
- Custom Tkinter
- Tkinter

## 環境
- Python 3.10 以上(pyファイル)
- Windows(exeファイル)


## 起動及び使用手順
main.exeファイルの実行
もしくはコマンドプロンプト(プロジェクトルート)で以下コマンドを実行  
python -m apps.release_porter.main  

※python -m はPythonモジュールをスクリプト(実行用ファイル)として実行するためのコマンドラインオプション  

1. 対象プログラムフォルダを選択ボタンを押下  
2. 対象プログラムファイルを選択ボタンを押下
※フォルダ・ファイルは必要なものを選択。どちらかの実行は必須ですが、両方実行の必要はありません。  
3. ツリービューに選択したフォルダ・ファイルが表示されます。
フォルダの中は展開された状態で表示されます。  
4. プレビュー状況で保存するボタンを押下
フォルダ保存のダイアログが開き、選択したフォルダにツリービューのフォルダ・ファイルがまとめてコピー・保存されます

## 簡易設計

## 簡易テスト
### ■正常系
1. 対象プログラムフォルダを選択ボタンでフォルダを選択 →  ツリービューに選択したフォルダ内の内容が表示される
2. 対象プログラムファイルを選択ボタンでファイルを選択 →  ツリービューに選択したファイル名が表示される
3. 1.2を実行後、プレビュー状況で保存するを選択 → フォルダ保存ダイアログでフォルダを選択 → 選択したフォルダ・ファイルが保存される
4. 1.2を実行後、クリアボタンを選択 → ツリービューの表示内容が消える事

### ■異常系
1. フォルダ・ファイルを選択していない状態でプレビュー状況で保存するボタン押下 → エラーダイアログ出力
